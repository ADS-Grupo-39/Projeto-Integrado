# Projeto-Integrado
Segunda entrega do Projeto Integrado desenvolvido pelo Grupo 39 do curso de ADS ddo SENAC

## Descrição
Software instrutivo desenvolvido para auxiliar usuários na consulta
de informações sobre primeiros socorros em diferentes situações de emergência.

## Funcionalidades
- Pesquisa de emergências
- Consulta de protocolos
- Sistema de favoritos
- Acesso aos procedimentos de primeiros socorros

## Tecnologias
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Como executar
1. Instalar e executar o UwAmp.
2. Colocar o projeto na pasta `www`.
3. Criar o banco de dados MySQL.
4. Configurar a conexão em `backend/conexao.php`.
5. Acessar o projeto pelo navegador.

## Estrutura do Projeto
- Projeto-Integrado/
- backend/          # Arquivos PHP e conexão com o banco
- database/         # Arquivos relacionados ao banco de dados (Consultas comentadas)
- imgs/             # Imagens utilizadas no projeto
- protocolos/       # Páginas dos protocolos de primeiros socorros
- scripts SQL/      # Scripts para criação e inserção dos dados (Execução automatica)
- index.html        # Página inicial
- script.js         # Funcionalidades e interações da página
- style2.css        # Estilos da página principal
- style-favoritos.css # Estilos relacionados aos favoritos
